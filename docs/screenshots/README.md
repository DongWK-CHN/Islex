# 截图目录

把应用截图放在这里（建议 3~4 张，PNG，宽度 1600px 左右），然后在仓库根目录的 `README.md`
「截图」一节把图片引用取消注释即可。

推荐拍这几张：

1. **收起态**：桌面顶部的灵动岛胶囊（含跑马灯边框）。
2. **媒体页**：封面 + 歌词 + 进度条（展开态）。
3. **天气页**：当前天气 + 7 天轨迹 + 空气质量。
4. **设置窗口**：外观自定义面板。

拍图小技巧：

```bash
# 只截取屏幕顶部中间区域（灵动岛所在位置），-x 静音、-o 去掉窗口阴影
screencapture -x -R"405,0,900,300" island.png
```
