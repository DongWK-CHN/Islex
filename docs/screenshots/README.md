# 截图目录

`README.md` 第一屏的演示图和正文截图都放在这里。文件名固定，别改大小写和空格，否则引用会断。

## 要拍的 5 个素材

| 文件 | 内容 | 尺寸 |
| --- | --- | --- |
| `notch-collapsed.png` | 收起态：桌面顶部中间那条胶囊，带跑马灯边框 | 1200 × 400，PNG |
| `media-player.png` | 媒体页（展开态）：封面 + 歌词 + 进度条 | 1200 × 800，PNG |
| `weather.png` | 天气页：当前天气 + 7 天轨迹 + 空气质量 | 1200 × 800，PNG |
| `settings.png` | 设置窗口：外观自定义面板 | 1600 × 1000，PNG |
| `demo.gif` | 10 秒演示：鼠标移入展开 → 切到媒体页 → 拖一下进度 → 移出收起 | 1200 × 600，GIF，10 秒，控制在 8 MB 以内 |

## 要求

- 用刘海屏 MacBook 拍，深色桌面背景，避免和胶囊边缘糊在一起。
- 图片统一 2x 缩放后导出，别做压缩到有锯齿；GIF 可以降到 15 fps 减体积。
- `demo.gif` 控制在 10 秒左右、无缝循环；超过 8 MB 的话 GitHub 页面加载会很慢，优先减帧率而不是减尺寸。

## 拍图命令

```bash
# 只截屏幕顶部中间区域（灵动岛所在位置），-x 静音、-o 去掉窗口阴影
screencapture -x -R"405,0,900,300" notch-collapsed.png
```

GIF 用 QuickTime 录屏，再按上面的尺寸和帧率导出即可。
